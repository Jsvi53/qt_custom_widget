
# 项目目录结构

```bash
+---assets      # 存放资源文件，图标、翻译文档等
|   \---icon
+---build       # 项目构建目录
+---database    # 数据库相关文件
+---docs        # 说明文档
+---examples    # 模块、功能示例
+---include     # 项目及模块头文件
|   +---base
|   \---driver
+---src         # 项目及模块源文件
|   +---base
|   \---driver
+---test        # 测试代码
\---third_party # 第三方资源等
│--CMakeLists.txt
│--README.md
```
